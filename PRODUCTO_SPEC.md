## ESTRUCTURA COMPLETA DE LA PLANTILLA

### MÓDULO 1 — Dashboard Principal (Home)
```
📊 Dashboard — Visión 360
├── 📌 Estado del mes (Ingresos actuales / Meta / Diferencia)
├── 🔥 Proyectos activos (top 3 con barra de progreso)
├── 💬 Clientes con seguimiento pendiente
├── 📅 Tareas de hoy / Esta semana
├── 🤖 Agentes activos / Automatizaciones en marcha
└── 💡 Próximas oportunidades (pipeline)
```

### MÓDULO 2 — Gestión de Clientes (CRM)
```
👥 CRM de Clientes
├── Base de datos de clientes (nombre, email, país, plataforma)
├── Estado: Prospecto / Activo / Completado / Inactivo
├── Historial de proyectos por cliente
├── Monto total facturado por cliente
├── Próxima fecha de seguimiento (con reminder)
└── Canal preferido de contacto (WhatsApp/Email/Telegram)
```

### MÓDULO 3 — Gestión de Proyectos
```
📁 Proyectos
├── Base de datos de proyectos
│   ├── Nombre del proyecto y cliente
│   ├── Carril: SIEMBRA / ACTIVO
│   ├── Estado: En progreso / Completado / En espera
│   ├── Fecha de entrega
│   ├── Precio acordado (en USD)
│   ├── % completado (barra de progreso)
│   └── Notas y entregables adjuntos
├── Vista Kanban (Por columnas de estado)
├── Vista Calendario (Por fecha de entrega)
└── Vista de Lista filtrable
```

### MÓDULO 4 — Finanzas & Cobros
```
💰 Tracker Financiero
├── Registro de ingresos
│   ├── Fecha, proyecto, cliente, monto, moneda (USD/EUR/BRL/RUB)
│   ├── Método de cobro (PayPal / Cripto TRX/SOL/POL / Transferencia)
│   └── Estado: Pendiente / Cobrado
├── Resumen mensual automático
│   ├── Total cobrado este mes
│   ├── Pendiente de cobro
│   ├── Meta mensual ($200 USD / personalizable)
│   └── % de progreso hacia la meta
└── Vista de tendencias (últimos 6 meses)
```

### MÓDULO 5 — AI Prompt & Automation Hub
```
🤖 Hub de IA & Automatizaciones
├── Librería de Prompts
│   ├── Categorías: Copywriting / Automatización / Código / Atención al cliente
│   ├── Prompt completo con variables {input}
│   ├── Plataforma: ChatGPT / Claude / Gemini / Coze
│   └── Rating personal (útil/no útil)
├── Registro de Automatizaciones (Workflows)
│   ├── Nombre del workflow
│   ├── Herramienta: n8n / Make / Python / Zapier
│   ├── Descripción corta del proceso
│   ├── Estado: Activo / Pausado / En desarrollo
│   ├── Cliente al que pertenece (o: Agente propio)
│   └── Link al workflow exportado
└── Templates de Propuesta Rápida
    ├── Propuesta corta para Fiverr/Upwork
    ├── Propuesta larga para proyectos complejos
    └── Follow-up de prospecto (3 versiones)
```

### MÓDULO 6 — Siembra & Pasivos
```
🌱 Carril SIEMBRA — Proyectos Pasivos
├── Base de datos de proyectos sembrados
│   ├── Nombre, descripción, plataforma
│   ├── URL de publicación
│   ├── Fecha de publicación
│   ├── Estado: Activo / Pausado / Abandonado
│   ├── Tráfico mensual (manual)
│   ├── Ingresos este mes ($)
│   └── Evaluación de abandono (3 meses sin actividad)
├── Checklist de despliegue SEO
└── Calendario de revisión de salud (cada 7 días)
```

### MÓDULO 7 — Exploración de Oportunidades
```
🔍 Pipeline de Oportunidades
├── Base de datos de oportunidades
│   ├── Nombre y descripción
│   ├── Fuente (Reddit / Kwork / Workana / etc.)
│   ├── Idioma del mercado
│   ├── Carril: SIEMBRA / ACTIVO
│   ├── Score de viabilidad (0-10)
│   ├── Tiempo estimado a 1° ingreso (días)
│   ├── Estado: Evaluando / Aprobada / Descartada / En ejecución
│   └── Notas
└── Vista filtrada: Top oportunidades con score > 7.5
```
